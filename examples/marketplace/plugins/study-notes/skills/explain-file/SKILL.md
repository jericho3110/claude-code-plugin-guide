# Explain a file

Read the file the user names (ask if they didn't name one). Then write:

1. **What it does**, in two or three plain sentences.
2. **Concepts used**: each language feature or design idea, with the line it appears on.
3. **One exercise**: a small change the reader can make to check they understood.

Keep it short. Don't edit the file.
